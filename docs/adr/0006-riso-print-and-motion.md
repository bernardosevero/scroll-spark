# 6. Riso Print direction, with motion in the app

**Status:** accepted, Nov 6, 2026

Buffer is for creators, so UI is a main focus and should spark joy. The owner chose direction A from three on the [design canvas](https://claude.ai/artifact/EAAmg5cCVLGi24JhtKxJGc), using their own Pantone colours. "Motion graphics" means joyful animation in the UI.

**Decision:** Riso Print: cream paper, navy ink, pink spark, hard offset shadows, Bricolage Grotesque and DM Sans, bundled with Fontsource. Motion uses the `motion` library and CSS, focused on five joy moments. Light theme only for the MVP.

**Consequences:** half a day on Thursday is reserved for a joy pass, taken from the dropped public conversation count. The [motion-graphics skills](https://github.com/Barty-Bart/motion-graphics) are optional extras for marketing video and aren't part of the app.
