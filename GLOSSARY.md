# Glossary

Use these words in code, UI and issues.

| Word                | Means                                                                                     | Not                                      |
| ------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------- |
| **Capture**         | Text and source a user chose to keep, stored in our database                              | An idea. A capture isn't in Buffer yet.  |
| **Inbox**           | The user's captures, waiting to be judged                                                 | Buffer's Ideas board                     |
| **Analysis**        | What the AI returns for a capture: summary, topic, angle, trend phrases, channel matches  | A score                                  |
| **Angle**           | A one-line suggestion for how this user could take the topic                              | The source's point                       |
| **Extension token** | A random, revocable sign-in the side panel sends as a bearer token, stored only as a hash | A Buffer token. It never reaches Buffer. |
| **Channel**         | A connected social profile in Buffer                                                      | An organization                          |
| **Channel profile** | A channel's cleaned posts, summaries and clusters, cached by us                           | Analytics                                |
| **Cluster**         | A named group of topics within one channel's posts                                        | A Buffer tag                             |
| **Fit**             | How a capture relates to one channel: it fits, or it's new. Counts and dates only.        | A prediction of success                  |
| **Freshness**       | When a channel last posted on this topic                                                  |                                          |
| **Demand**          | Google Trends links for the user to judge                                                 | A number we calculate                    |
| **Idea**            | A Buffer Idea, created when the user saves a capture                                      | A capture                                |
| **Draft**           | AI-written text in the editor, or a post saved to Buffer as a draft                       | The source text                          |
| **Queued post**     | A post added to a channel's Buffer queue. It may publish for real.                        | A draft                                  |
| **Flow test**       | A test of a user-visible flow, written first, that goes red before the code exists        | A unit test of one helper                |
| **Joy moment**      | One of the five animated moments in `docs/design-system.md`                               | Decoration elsewhere                     |
